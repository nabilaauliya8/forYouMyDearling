# Birthday Mission — Web Ucapan Ulang Tahun untuk Sahabat

Web ucapan ulang tahun dengan tema army green, olive, khaki, dan camouflage. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Struktur folder

```text
ulang_tahun_sahabat_army/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Cara menjalankan di VS Code

1. Ekstrak file ZIP.
2. Buka VS Code.
3. Pilih **File → Open Folder**, lalu pilih folder `ulang_tahun_sahabat_army`.
4. Buka `index.html`.
5. Klik kanan pada file dan pilih **Open with Live Server** jika ekstensi Live Server sudah terpasang. Alternatifnya, buka `index.html` langsung di browser.

## Cara menambahkan foto kenangan

Klik **Pilih foto kenangan** pada bagian Galeri Kenangan, lalu pilih satu atau beberapa foto dari komputer. Foto hanya ditampilkan secara lokal di browser dan tidak diunggah ke server. Untuk menampilkan foto secara permanen bagi orang lain, masukkan file foto ke proyek dan sesuaikan HTML atau hosting web.

## Cara menambahkan musik

Klik tombol **Musik: OFF** di kanan atas, lalu pilih file audio (misalnya MP3) dari komputer. Setelah dipilih, musik akan diputar jika browser mengizinkan. File audio tidak disertakan dalam ZIP, jadi gunakan file musik milik sendiri atau yang boleh digunakan.

## Personalisasi

- Ubah sapaan `Bro!` di `index.html` menjadi nama panggilan sahabat.
- Ubah teks surat dan pesan rahasia langsung di `index.html`.
- Warna utama bisa disesuaikan di bagian `:root` pada `css/style.css`.

Catatan: tema camouflage dibuat dengan CSS, sehingga tidak membutuhkan gambar latar tambahan atau koneksi internet untuk menampilkan teksturnya. Google Fonts akan memakai font cadangan jika koneksi internet tidak tersedia.
